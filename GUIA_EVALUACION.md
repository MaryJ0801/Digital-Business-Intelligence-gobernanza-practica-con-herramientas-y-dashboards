# Guía rápida para evaluación

Esta guía está pensada para facilitar la revisión académica del portafolio **Digital Business Intelligence: gobernanza práctica con herramientas y dashboards**.

## 1. Punto de entrada recomendado

Abrir primero la portada publicada:

<https://maryj0801.github.io/Digital-Business-Intelligence-gobernanza-practica-con-herramientas-y-dashboards/>

Desde ahí se puede navegar a todos los entregables integrados del curso.

## 2. Orden sugerido de revisión

1. **Semana 01 — Portafolio central**
   - Propósito: creación y organización inicial del portafolio.
   - Evidencia: portada principal, README y documentación en `docs/`.

2. **Semana 02 — Alineamiento Dinámico Huawei**
   - Pivote: alineamiento dinámico.
   - Entregable: dashboard ejecutivo tipo command center.
   - Enlace: <https://maryj0801.github.io/Digital-Business-Intelligence-gobernanza-practica-con-herramientas-y-dashboards/Semana02/>

3. **Semana 03 — Cultura y Liderazgo Digital FCC**
   - Pivote: cultura y liderazgo digital.
   - Entregable: dashboard interactivo sobre modernización pública.
   - Enlace: <https://maryj0801.github.io/Digital-Business-Intelligence-gobernanza-practica-con-herramientas-y-dashboards/Semana03/>

4. **Semana 04 — Innovación Centrada en el Cliente**
   - Pivote: innovación centrada en el cliente.
   - Caso: RAPS GmbH y plataforma myRAzept.
   - Enlace: <https://maryj0801.github.io/Digital-Business-Intelligence-gobernanza-practica-con-herramientas-y-dashboards/RAPS_myRAzept/>

5. **Semanas 05 a 07 — Asistente Académico COMEX UTN**
   - Pivotes: agilidad operativa, acceso y uso de datos, ecosistemas colaborativos.
   - Entregable: app web creada con Lovable e integrada al portafolio.
   - Página del portafolio: <https://maryj0801.github.io/Digital-Business-Intelligence-gobernanza-practica-con-herramientas-y-dashboards/Semana05/>
   - App publicada: <https://tutor-comex-utn.lovable.app>

6. **Portafolio de Datos**
   - Propósito: evidencia complementaria de BI, dashboards, gobernanza e IA aplicada.
   - Enlace: <https://maryj0801.github.io/Digital-Business-Intelligence-gobernanza-practica-con-herramientas-y-dashboards/PortafolioDatos/>

## 3. Competencias evidenciadas

- Inteligencia de negocios aplicada.
- Gobernanza de datos y trazabilidad.
- Diseño de dashboards ejecutivos.
- Visualización de datos con HTML, JavaScript, Chart.js y Plotly.
- Uso de IA sin código mediante Lovable.
- Transformación de normativa y procesos en herramientas digitales.
- Organización profesional de repositorios y documentación técnica.
